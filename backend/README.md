# ⚙️ AI-RD Proposal Evaluation System - Backend API

FastAPI asynchronous backend powering the **AI-Based Research Proposal Evaluation System**.

## 🚀 Quick Start

1. **Activate Virtual Environment**:
   ```powershell
   .\venv\Scripts\Activate.ps1
   ```

2. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run Server**:
   ```bash
   uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
   ```

4. **API Interactive Documentation**:
   - Swagger UI: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
   - ReDoc: [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)

For full project details, environment setup, and architecture diagrams, please refer to the [Root README.md](../README.md).
